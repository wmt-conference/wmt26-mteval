# Changelog

All notable changes to the WMT26 MT-Eval data release. The version of the release is the version
of `src/wmt26_mteval/__init__.py`.

## v0.9: pre-release (date: YYYY-MM-DD, to be set at release)

The first release: typed data configs and documentation. The steps that make the release, among
them setting the date above, are in [`RELEASE.md`](RELEASE.md).

### Added

- Hugging Face dataset `wmt/wmt26-mteval-data`, with seven typed configs, each with a single split
  named `evaluation` that loads with `datasets>=2.18`:
  - `items`: the test items with source, reference, reference type and the columns parsed from
    `item_id`;
  - `pairs`: the candidate translations of every item, with `is_reference_candidate` and
    `hyp_is_empty`, and without gold columns;
  - `submissions` and `baselines`: the predictions of every participant run and organiser
    baseline, one row per run, item and system (`baselines.variant` is `official` or `alt`);
  - `systems`: one row per evaluator run, from allow-listed model-card answers and the curated
    names of the findings paper;
  - `mt_systems` and `challenge_sets`: the translation systems and the challenge sets.
- The organisers' `wmt26-grand.parquet`, unchanged, as the `grand` config; it needs
  `datasets>=4.7.0`.
- The dataset card, rendered from `hf/README.template.md` and the build manifest, so that every
  number in it is counted from the data.
- `docs/FORMAT.md` and `data/MANIFEST.tsv`, generated by `scripts/render_docs.py`; `docs/ERRATA.md`
  (where the findings paper and the data differ); `docs/RELEASE.md` (the release guide).
- `instructions/baseline-prompts.md`: the prompts of the LLM baselines (Appendix E of the findings
  paper).
- `README.md`, `CITATION.cff` and `scripts/download.py`.
- The tooling behind them: `scripts/build_hf.py` (a deterministic build with `build_manifest.json`),
  `scripts/validate_hf.py` (the card and the manifest, row counts, Table 2, personal data, schemas,
  the keys that link the configs, the texts of `items` and `pairs`, the Task 2 scores of the `alt`
  baselines, and a round trip of every run against the grand file), `scripts/check_loading.py`
  (every config loads with `datasets` 2.18.0, 4.0.0 and 5.1.0) and `scripts/scrub_model_cards.py`
  (allow-list scrubbing of model cards).

### Not in v0.9

Planned for v1.0, which also needs the organisers' scoring code:

- a gold config and gold columns with the human annotations (General MT's public release is at
  <https://github.com/wmt-conference/wmt26-general-mt/releases/tag/humeval>; the unchanged `grand`
  config still carries the raw annotation records);
- `converted`, the predictions converted between tasks;
- `results` and the `metrics/` package that reproduces the paper's tables.

### Known issues

- Differences between the findings paper and the data are in [`ERRATA.md`](ERRATA.md).
